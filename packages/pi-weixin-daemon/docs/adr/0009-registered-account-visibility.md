# ADR-0009：账号登记与 monitor 生命周期分离

- 状态：已采纳（Accepted）
- 关联：Issue #36、[ADR-0007](0007-account-name-id-boundary.md)

## 背景

ADR-0007 将在线 name 解析交给 daemon 的 account.list。若该列表仅包含 monitor，登出先停止 monitor、后删除凭据时，一旦删除失败，仍登记的账号就无法再按 name 选择。

## 决策

- account.list 以持久账号索引为来源，合并 monitor 的运行状态；无 monitor 的已登记账号返回 stopped，保留可用的 name、userId、savedAt。项目绑定读取持久配置，避免失败登出后展示已解除的绑定。
- 保留先解绑、停止 monitor，再删除文件、注销索引的顺序，避免运行中的 monitor 写回已删除文件。
- 辅助文件先删除，凭据文件最后删除；凭据中的 name 在辅助清理失败时仍保留。删除失败传播错误并保留索引，允许修复权限后在线按 name 重试。

## 后果

账号存在与账号正在运行不再混为一谈。修复不引入存储迁移、额外恢复状态或事务回滚；已完成的解绑和文件删除不会撤销。凭据清理之外的索引写入故障仍按原有错误路径暴露，不承诺跨文件事务性。
